## 1. 시스템별 워크플로우

### 1.1 전체 시스템 아키텍처 데이터 흐름

```
[어르신] ──음성──► [L1. 오미 디바이스]

                    │ 엣지 처리   │  Wake Word 탐지 (<500ms)
```

### 1.2 오미 디바이스 내부 처리 흐름

```
[어르신 발화]
      │
      ▼
[Wake Word 탐지] ──실패──► [대기 상태 유지]
      │ 성공
      ▼
[LED: 파랑 점멸 — 인식 중]
      │
      ▼
[엣지 ASR: 음성 → 텍스트]
  - Whisper distil 한국어 fine-tune (표준어 + 방언 4종)
  - RTF ≤ 0.1 (Jetson Orin 기준)
      │
      ▼
[방언 정규화기] ← v1.1 추가 (SC-09)
  - 경상·전라·충청·제주 방언 → 표준어 변환
  - 방언 정규화 사전 + 컨텍스트 기반 보정
  - 정규화 실패 시 원문 그대로 전달 (폴백)
      │
      ├──[로컬 긴급키워드 감지?] ──YES──► [Level 3 즉시 알림] → [보호자 전화 연결]
      │         NO
      ▼
[네트워크 가용?]
  ├── YES ──► [클라우드 전송] ──► [Dialog Core 처리]
  └── NO  ──► [엣지 폴백 모드]
                  - 복약 알림 (로컬 스케줄러)
                  - 저장된 자서전 기반 간단 대화
                  - "잠깐 연결이 안 돼요, 조금 후 다시 얘기해요" 안내
      │
      ▼
[LED: 주황 점멸 — 생각 중]
      │
      ▼
[응답 텍스트 수신 (스트리밍)]
      │
      ▼
[TTS 합성 (스트리밍 — 첫 청크 즉시 재생)]
      │
      ▼
[LED: 초록 — 발화 중]
      │
      ▼
[어르신 발화 대기 (5초 침묵 허용)]
      │
      ▼
[대화 종료 이벤트] ──► [자서전 DB 업데이트 (이벤트 기반 동기화)]
```

**지연 목표:** Wake Word → 첫 TTS 음절 ≤ 1,500ms (평균 목표 ~900ms)

### 1.3 자서전 엔진 데이터 처리 흐름

```
[대화 응답 텍스트 수신]
      │
      ▼
[NLU: 발화 분석]
  - 시점 분류 (유년기/학창/청년/중년/현재)
  - 주제 분류 (인물/장소/사건/감정)
  - 신규 Entity 추출 (사람 이름·지명·날짜)
  - 감정 강도 스코어 (0.0~1.0)
      │
      ▼
[자서전 타임라인 DB 저장]
  {
    period: "유년기",
    topic: "장소",
    text: "경상도 밀양, 낙동강 옆 거주",
    confidence: 0.9,
    emotion_score: 0.3,
    source_session_id: "sess_20260522_001",
    created_at: timestamp
  }
      │
      ▼
[메모리그래프 갱신]
  - 노드 추가/강화 (Person·Place·Event·Emotion)
  - 엣지 가중치 갱신 (감정 강도 × 언급 빈도)
      │
      ▼
[RAG 벡터 임베딩 갱신]
  - 한국어 임베딩 모델 (768d)
  - pgvector 인덱스 갱신
      │
      ▼
[빈칸 탐지 & 다음 질문 우선순위 재계산]

  Coverage Score  = 채워진 셀 / 전체 셀
  Recency Score   = 마지막 언급 후 경과일 / 최대허용일
  Emotion Score   = 감정 강도 (강한 셀 우선)
  Coherence Score = 모순 감지 시 낮아짐

  Question Priority = 0.5×(1-Coverage) + 0.3×Recency + 0.2×Emotion

  → 최고 점수 셀의 질문 템플릿 선택
  → 다음 세션에서 오미가 해당 질문 선제 사용
```

### 1.4 LLM 파이프라인 흐름 (응답 생성)

```
[Dialog Core 오케스트레이터 수신]
      │
      ▼
[컨텍스트 조립]
  ┌─────────────────────────────────────────┐
  │ System Prompt (캐시됨):                  │
  │  - 페르소나 정의 (친구/자매/형제)          │
  │  - 안전 가드레일 규칙                      │
  │  - 오미 행동 원칙 (§7.4)                  │
  │                                         │
  │ 자서전 컨텍스트 (RAG 인출, 캐시됨):        │
  │  - 어르신 핵심 생애사 청크 (상위 5개)       │
  │  - 최근 대화 요약 (최근 3세션)             │
  │                                         │
  │ 현재 발화 (비캐시):                       │
  │  - 어르신 입력 텍스트                      │
  │  - 감정 신호, 대화 컨텍스트                 │
  └─────────────────────────────────────────┘
      │
      ▼
[LLM API 호출 (스트리밍)]
  - TTFT (첫 토큰 출력) ≤ 200ms 목표
  - 안전 필터: 의료 단정·인간 사칭·부적절 발화 차단
  - 환각 감지: "잘 모르겠어요" 폴백
      │
      ▼
[응답 후처리]
  - 문장 단위 TTS 전송 (스트리밍)
  - 감정 분류 → LED 피드백 코드 결정
  - 감정 부조화 가드 적용 (v1.1, SC-10)
      sadness ≥ 0.6 → 감탄/축하 응답 차단 → EMPATHY_RESPONSES로 교체
  - 이상징후 신호 추출 → L4 Operate 전달
      │
      ▼
[오미 TTS 재생] + [자서전 DB 업데이트]
```

## 2. 사용자별 워크플로우

### 2.1 어르신 (1차 사용자) — 전체 여정

```
┌──────────────────────────────────────────────────────────┐
│                   어르신 사용자 여정                          │
│              (일상 사용 기준, MCI~초로기 치매)                   │
└──────────────────────────────────────────────────────────┘

【최초 도입 단계】
  가족·시설이 오미 설치
      │
      ▼
  온보딩 인터뷰 (가족 참여)
  - 이름·호칭 설정 ("오미야" 또는 "오미")
  - 페르소나 선택 (친구/자매/형제)
  - 가족 사진·유물 사진 업로드 (선택)
  - 복약·일정 등록
  - 치매 단계 설정 (가족이 앱에서)
      │
      ▼
  첫 대화 (오미 선제 시작)
  "안녕하세요, 저는 오미예요. 사람은 아니지만 어르신 이야기를 함께 기억하고 싶어요."

【일상 사용 단계 — 반복 루프】

  아침
  ├─ 오미: 안부 인사 + 날씨 언급
  ├─ 복약 리마인더 (설정 시간)
  └─ 자서전 대화 시작 (빈칸 우선 질문)

  낮
  ├─ 자유 대화 (어르신 주도 또는 오미 주도)
  ├─ 인지활동 콘텐츠 (퀴즈·시대 노래 — S2 기능)
  └─ 감정 신호 모니터링

  저녁
  ├─ 오늘 대화 요약 ("오늘 첫 직장 이야기 들었어요, 정말 대단하셨어요")
  ├─ 가족 음성메시지 재생 (있는 경우)
  └─ 수면 시간 대화 최소화 (22:00 이후)

【자서전 심화 단계 (3~6개월)】
  - 빈칸 채워짐에 따라 오미의 질문이 더 구체적·개인화
  - 페르소나가 "그 어르신만의 친구"로 진화
  - 자서전 책자·오디오북 생성 제안

【위기/이상 단계】
  감정 고조·위기 발화 감지
      │
      ▼
  Level 판별 (§7.4 참조)
      ├── Level 1: 공감 대화 → 일일 요약 포함
      ├── Level 2: 공감 + 보호자 즉시 알림
      └── Level 3: 보호자 전화 + 1393 안내
```

### 2.3 가족/보호자 워크플로우

```
【가족 앱 주요 업무 흐름】

[앱 설치 & 초대]
  어르신 설정 후 가족 초대 코드 발급
  → 가족 앱 설치 → 권한 등록 (열람/음성메시지/알림)
      │
      ▼
【일상 사용】
  ┌─ 알림 수신 — 3-Tier 체계 (v1.1, ADR-11)
  │    ├── Tier 1 긴급 Push (즉시): Level 2·3 위기, 복약 거부 2회
  │    │     "어머니에게 위기 신호가 감지되었습니다. 지금 바로 확인해 주세요."
  │    ├── Tier 2 인앱 알림 (21:00 자동): 일일 요약, Level 1 이상징후
  │    │     "어머니 오늘 23번 대화하셨어요. 6·25 피란 이야기를 처음 해주셨어요."
  │    │     ※ 세션 주제 요약 포함 (회상 시점·화제 자동 요약)
  │    └── Tier 3 주간 리포트 (매주 월요일): 감정 트렌드·자서전 Coverage 변화량
  │          알림 피로도 최소화 — Tier 1만 홈화면 Pop-up
  │
  ├─ 자서전 열람
  │    - 타임라인 뷰: 시기별 어르신 이야기
  │    - 사진 갤러리: 업로드 사진 + 관련 이야기 연결
  │    - 비공개 영역 제외 (어르신 설정 준수)
  │
  ├─ 음성메시지 전송
  │    - 녹음 → 전송 → "오미가 전해드렸어요" 확인
  │    - 오미가 적절한 시간에 자연스럽게 재생
  │
  ├─ 자서전 책자/오디오북 주문 (6개월 이상 사용 시)
  │    - 자서전 완성도 확인
  │    - 추가 사진·메시지 첨부
  │    - 인쇄/디지털 선택 → 주문
  │
  └─ 유산 패키지 수령 (v1.1, F-08) — 탈퇴·사망 시 자동 제공
       - 주보호자에게 Tier 1 긴급 알림 + 이메일 발송
       - 자서전 PDF (전체) + 음성 클립 ZIP (어르신 실제 목소리)
       - 서명된 다운로드 URL (TTL 90일, SC-12)
       - 프라이버시 정책 평이한 언어 설명 포함 (PRD §16)
```

| 가족 업무 | 빈도 | 채널 | 예상 소요 시간 |
|---|---|---|---|
| Tier 1 긴급 알림 대응 | 필요 시 | Push → 전화 | 즉시 |
| Tier 2 일일 요약 확인 | 매일 | 앱 인앱 알림 | 1~3분 |
| Tier 3 주간 리포트 확인 | 주 1회 | 앱 | 3~5분 |
| 자서전 열람 | 주 1~2회 | 앱 | 5~15분 |

### 3.4 이상징후 감지 & 알림 워크플로우

```

  ③ 수면 패턴 이상 (야간 대화 급증)
  ④ 복약 미확인 연속 N회
  ⑤ 무응답 시간 이상 (평소 패턴 벗어남)
  ⑥ 위기 발화 키워드
      │
      ▼
[이상징후 판별 엔진]
  - 기준선(Baseline): 개인별 최근 30일 평균
  - 임계값: 기준 대비 2σ 이상 이탈 → 이상

  이상 신호 레벨 판별:
  ┌─────────────────────────────────────────────────┐
  │  Level 1 (정보):  우울 키워드 증가, 발화량 약간 감소  │

  ├─────────────────────────────────────────────────┤
  │  Level 2 (주의):  무응답 3일, 우울 신호 급증         │
  │  → 즉시 보호자 앱 푸시 알림                        │
  │  → 사례관리자 대시보드 하이라이트                   │
  ├─────────────────────────────────────────────────┤
  │  Level 3 (긴급):  위기 발화, 복약 과다 의심          │
  │  → 보호자 전화 자동 연결 시도                      │
  │  → 자살예방상담전화(1393) 안내                     │
  │  → 사례관리자 SMS 즉시 발송                        │
  └─────────────────────────────────────────────────┘
      │
      ▼
[알림 발송 — 3-Tier 체계 (v1.1, ADR-11)]
  ┌───────────────────────────────────────────────────────┐
  │  Tier 1 긴급 Push (즉시, 홈화면 Pop-up)                │
  │   Level 2: 앱 Push → (5분 미확인) SMS                  │
  │   Level 3: 앱 Push + SMS + 전화 자동 다이얼            │
  ├───────────────────────────────────────────────────────┤
  │  Tier 2 인앱 알림 (앱 내 배지, 일반 사항)               │
  │   Level 1 이상징후, 일일 요약 (21:00)                   │
  │   복약 미확인 (1회), 발화량 소폭 감소                    │
  ├───────────────────────────────────────────────────────┤
  │  Tier 3 주간 리포트 (매주 월요일 Push 1회)              │
  │   감정 트렌드, 자서전 Coverage 변화, 복약 순응도          │
  │   → 알림 피로도 최소화 목적 (리빙랩 F-04)               │
  └───────────────────────────────────────────────────────┘

[보호자 대응 기록]
  - 대응 여부, 대응 시간 기록
  - 사례관리자 피드백 입력 (방문 결과 등)
  - 대응 완료 시 Level 해제
```

### 3.5 자서전 책자·오디오북 생성 워크플로우

```
【자서전 산출물 생성 — B2C 핵심 차별화】

[트리거]
  - 자서전 완성도 ≥ 60% (6개월 이상 사용 시 자동 제안)
  - 가족이 앱에서 직접 주문
      │
      ▼
STEP 1. 자서전 데이터 검토 (앱)
  - 시점별 이야기 목록 미리보기
  - 비공개 영역 확인 (제외됨)
  - 추가 사진·메시지 첨부 (선택)
      │
      ▼
STEP 2. 편집 옵션 선택
  ┌──────────────────────────────┐
  │ 편집 원칙 선택:              │
  │  □ 시간순 (유년기→현재)      │
  │  □ 주제별 (인물/장소/사건)   │
  │ 분량: 60p / 80p / 100p      │
  │ 문체: 구술체 / 3인칭 서술체  │
  │ 어르신 실제 발화 클립 포함   │
  └──────────────────────────────┘
      │
      ▼
STEP 3. AI 자동 편집 (자서전 생성기)
  - 구조화된 DB → 서사 문단 자동 생성 (LLM)
  - 사진 자동 배치 (관련 시기에)
  - 감정 강도 높은 이야기 강조 처리
  - 1인칭 구술 스타일 유지
  - 비공개 영역 자동 제외
      │
      ▼
STEP 4. 가족 검토 & 수정
  - 앱에서 챕터별 미리보기
  - 수정 요청 텍스트 입력
  - 추가 내용 직접 작성 옵션
  - 최대 3회 수정 가능 (기본)
      │
      ▼
STEP 5. 산출물 생성
  ┌─ PDF 자서전 책자
  │   → 고품질 인쇄 파일 (A5/A4 선택)
  │   → 하드커버 인쇄·배송 주문 (5~10만원)
  │
  ├─ 오디오북 (TTS 버전)
  │   → 오미 목소리로 낭독 (MP3)
  │   → 선택: 가족 음성 클립 삽입
  │   → 앱에서 스트리밍·다운로드
  │
  └─ 디지털 자서전 (앱 전용)
      → 타임라인 인터랙티브 뷰
      → 가족 공유 링크
```

### 3.6 복약·일정 관리 워크플로우

```
【복약 관리 — 어르신 안전의 기초 기능】

[설정 단계]
  가족/보호자가 앱에서:
  - 약 이름, 복약 시간, 횟수 입력

  [어르신 응답]
  ├── "먹었어" / "응" / "알았어"

  │    → 재알림 1회
  │    무응답 (5분 추가)

       → "알겠어요. 조금 있다 다시 알려드릴게요." (30분 후 재알림)

      │
      ▼
[복약 패턴 분석]
  - 주간 복약률 계산
  - 연속 미복약 N일 시 Level 2 이상징후 처리
```

### 3.7 위기 발화 대응 워크플로우 (긴급 프로토콜)

```
【위기 대응 — 3단계 프로토콜】

[위기 발화 감지]
  로컬 키워드 탐지 (엣지, 즉각 반응) +
  LLM 문맥 판별 (클라우드, 정밀 분류)
      │
      ▼
┌─────────────────────────────────────────────────────────┐
│  LEVEL 1 — 정보 수준                                     │
│  키워드: "외로워", "심심해", "보고 싶어", "힘들어"         │
│  오미: [질문 중단] → 공감 응답                            │
│        "어르신, 많이 힘드시구나. 제가 옆에 있을게요."      │
│        → 3~5초 침묵 → "좋아하시는 노래 틀어드릴까요?"     │
│  백엔드: 감정 신호 기록 → 일일 요약에 포함               │
│  알림: 없음 (요약에만 포함)                               │
└─────────────────────────────────────────────────────────┘
      │
┌─────────────────────────────────────────────────────────┐
│  LEVEL 2 — 주의 수준                                     │
│  키워드: "살기 싫어", "힘들어 죽겠어", "아무도 없어"       │
│  오미: 공감 + 연결                                        │
│        "어르신, 많이 힘드시구나. 걱정이 돼서요.            │
│         따님(박미경님)한테 연락해드릴게요."                │
│  백엔드: 즉시 보호자 앱 푸시 알림 (5분 미확인 시 SMS)     │
│          사례관리자 대시보드 하이라이트                   │
│  알림: 보호자 + 사례관리자                                │
└─────────────────────────────────────────────────────────┘
      │
┌─────────────────────────────────────────────────────────┐
│  LEVEL 3 — 긴급 수준                                     │
│  키워드: "죽고 싶어", "약을 많이 먹었어", "끝내고 싶어"    │
│  오미: 즉각 대응                                          │
│        "어르신, 많이 힘드시구나. 지금 바로 도움을 드릴게요. │
│         자살예방상담전화 1393에 연결해드릴게요."            │
│  백엔드: 보호자 전화 자동 다이얼 시도 → 사례관리자 SMS     │
│          전체 대화 로그 보존 (증거 보전)                  │
│          운영팀 긴급 알림                                 │
│  알림: 보호자(전화) + 사례관리자(SMS) + 운영팀             │
└─────────────────────────────────────────────────────────┘

[사후 관리]
  - 보호자/사례관리자 대응 결과 기록
  - 해당 시점 자서전 질문 일시 보류
  - 다음 세션: 안정 콘텐츠 우선 (음악·가벼운 대화)
  - 반복 발생 시 자동 집중 모니터링 설정
```
