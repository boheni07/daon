## 완료된 작업

### P1 — HW 스펙 (§9.1)
- 폼팩터·음성·컴퓨팅·전원·인증·원가 목표 테이블 추가

### P2 — 응답 지연 분석 (§9.2)
- 파이프라인 단계별 지연 분해, 1.5초 달성 조건 명시

### P3 — 대화 UX 플로우 (§7.4)
- 시나리오 A~D (정상·실패·감정·위기), 캐릭터 행동 원칙, LED 피드백 코드

### P4 — 치매 단계별 대응 (§5.3)
- MCI·초로기·중등도·중증 4단계 전략 테이블

### P5 — 위기 발화 프로토콜 (§8)
- Level 1~3 분류 체계, 각 단계별 오미 행동·알림 대상

### P6 — ADR 6건 (§9.4)
- ADR-01~06: ASR·LLM·벡터스토어·동기화·캐싱·앱 플랫폼 결정

### 추가 완료
- §5 페르소나 시나리오 3 추가 (박정희, 중등도 치매)
- §11 KPI ZBI·보호자 앱·유산 지표 추가
- §14 후속 문서 로드맵 테이블화
